# RBIF111-Bioinformatics
**Student:** Martin Djamongue
**Institution:** Brandeis University
**Course:** RBIF 111 - Mathematical Modeling for Bioinformatics

## Course Overview

This repository contains my coursework for RBIF 111, covering statistical
modeling and bioinformatics analysis in R across 8 weeks.

## Repository Structure

- `Week1/` - R fundamentals, data acquisition, reproducible reporting
- `Week2/` - Probability distributions, hypothesis testing, power analysis
- `Week3/` - Linear models, non-parametric tests, GAMs
- `Week4/` - Confidence intervals, survey analysis
- `Week5/` - ANOVA, survival analysis, clinical trial interpretation
- `Week6/` - Multiple testing, resampling, adverse event detection
- `Week7/` - Regression, cross-validation, penalized regression
- `Week8/` - Advanced modeling, causal inference, meta-analysis

## Tools

R, RStudio, Bioconductor, ggplot2, mgcv, glmnet, survival, mice, pROC
